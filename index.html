Cómo funciona el modo comparativo

Al activar la comparativa se muestran simultáneamente el año principal y el de referencia para cada mes, calculando la desviación porcentual. El radar muestra la distribución relativa por servicio entre ambos ejercicios.

Importación de datos

Sube tu CSV acumulado. El sistema detecta automáticamente el año, separador y mapea cada fila al catálogo de 22 servicios mediante coincidencia inteligente. Puedes copiar la tabla directamente en Excel con Ctrl+C.
